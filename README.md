~ BMI & Healthy Routine Assistant
A beginner-friendly Python project that calculates Body Mass Index (BMI) and provides general educational guidance on food, healthy daily routines, and BMI awareness — all through a simple menu-driven console program.

-> Overview:
 BMI & Healthy Routine Assistant helps users quickly calculate their BMI and get general data, educational tips on nutrition, daily routines, and what BMI actually means. The project is organized into separate Python modules, making the code user friendly , readable, and easy to maintain or extend.

->Note:
This is not a dedicated  medical tool — it is an educational project that shows practical use of Python fundamentals like functions, modules, input validation, conditionals, and loops.

->Features
1.Calculate BMI
2.Takes weight (kg) and height (cm) as input
3.Calculates and displays BMI instantly
4.Shows the corresponding BMI category with simple feedback
5.Validates input and handles invalid or non-positive values gracefully
6.Food Suggestions
7.General, balanced meal suggestion ideas
8.Purely educational — not medical or dietary advice
9.Healthy Daily Routine
10.Simple guidance for morning, daytime, evening, and night routines
11.Learn About BMI
12.Explains what BMI is and the formula behind it
13.Clarifies that BMI is a general screening tool, not a full health assessment.

->Technologies / Tools Used
1.Python 3
2.Jupyter Notebook (for testing/demo)
3.Git & GitHub (version control)

->Project Structure
├──> main.py           #Main menu and program flow
├──>bmi.py            # BMI calculation and input validation
├──> food.py            #Food suggestions
├──> routine.py        # Healthy daily routine guidance
├──> information.py    # BMI information and formula explanation
├──>Testing.ipynb      # Testing and demonstration of the project
└──>README.md

->How to Run
1. Download or clone this repository.
2. Open the project folder in Python or Jupyter.
3. Run `main.py`.
4. Select an option from the menu.

->Testing:
The project includes a Testing.ipynb notebook for verifying functionality and demonstrating example outputs.
To run the tests:
1.Install Jupyter if you don't have it:
   pip install notebook
2.Launch Jupyter Notebook:
   jupyter notebook
3.Open Testing.ipynb and run all cells.
Check that:
BMI is calculated correctly for valid inputs
Invalid inputs (negative numbers, zero, or non-numeric values) are handled with clear error messages
Each menu option (Food, Routine, Information) returns expected output.
